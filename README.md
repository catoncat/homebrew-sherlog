# Sherlog Homebrew Tap

Homebrew tap for [Sherlog](https://github.com/catoncat/sherlog), a standalone CLI for searching local agent session logs.

## Install


directly from this tap:

```sh
brew tap catoncat/sherlog
brew install sherlog
```

Or in one command:

```sh
brew install catoncat/sherlog/sherlog
```

## Upgrade

```sh
brew update
brew upgrade sherlog
```

The formula is synchronized from the native assets published by the main Sherlog repository.
